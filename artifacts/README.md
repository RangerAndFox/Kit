# Artifact privacy policy

Do not commit screenshots, recordings, exports, or generated handbooks made
from live Ranger & Fox systems. This includes Slack, Google Sheets, Dropbox,
Frame.io, Harvest, Boords, ElevenLabs, dashboards, and project-control views.

Documentation committed to this repository must use synthetic data and
redacted fixtures created specifically for public repository use. Keep live
captures in an access-controlled workspace outside Git, and review images and
embedded document media before publishing.
